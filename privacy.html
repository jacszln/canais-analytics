Privacy Policy

Last updated: October 5, 2026

Canais Analytics is a personal tool used only by its owner to read the analytics of the owner's own YouTube channels.

What it accesses

With the owner's authorization, it requests read-only access to the YouTube Analytics API, the YouTube Reporting API and the YouTube Data API (scopes yt-analytics.readonly and youtube.readonly). It cannot upload, edit or delete anything.

How the data is used and stored

The data is used only to evaluate the performance of the owner's own videos. It is stored only on the owner's computer. It is never sold, shared with third parties or used for advertising.

Other people

The tool has no other users and collects no data about anyone other than the owner's own channels.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
